# CPR: Functional Agent

Good morning, looking to share out my recently put-together semi-functional agent. My player's are big into the roleplay aspects that come with an Agent, and after growing tired of trying to track text threads in chat, this got put together. The GM handles everything on their side from the "GM Phone", while players have access to their own individual phones depending on their equipped gear. 

**Optionally connects to SimpleCalendar & Small Time for time/date tracking.**

## Install

1. Install the included module into your "Modules" folder, it is not currently available elsewhere.
2. Give any PC character an Agent or Internal Agent item. Check the Module Settings to configure alternative gear names. Biomonitor also works.
3. When a PC selects their token, they'll see a small UI button appear that enables them to open their agent.

The GM needs to be online for the Agent's to function. The GM serves as a networking middle-man for most of the Agent's communicative features.

## GM Customization (GM Phone -> Control)

- Characters: This list populates from assigned/Owned 'Character' type sheets. You can disable cellular service from this menu.
- Apps: Select which apps you'd like your PCs to have access to
- This GM Phone: Set your own preferences for display
- Every Phone: Set player-wide preferences. Some of these can be modified by the player. You can modify the Calendar settings here.
- Labels: Money formatting, app names and a few other strings. **Unfortunately no translation support at this time**
- Icons: Font Awesome icons if you'd like to change them.
- Clear App Data: Some selections for wiping things.

**Module Settings:** Module Settings allows you to set some custom sounds, disable/enable in-world sounds, the radius of those sounds and some volume configuration.

## Messages (BabelChat)

- Standard modern messaging system, with groupchats, photo/map/BangMe integration, job offers, and reactions.
- Photos can be enabled or disabled by the GM.
- GM can "Hide Caller ID" and text as an "Unknown Number" if they'd like. You can reveal it later if you'd like.
- If the GM cuts signal to someone phones (under Control), nearly all notifications (Claude-willing) should be held until service returns. 
- Text tones can be heard in the world from an unsilenced Agent.
- **"Services"**. Although Trauma Team exists as it's own app, you can also use Services as more "scripted" NPC interactions.
  - NCPD. You have buttons indicating "Request Assistance", which sends a text to the GM. 
  - Additionally for the NCPD, you could have multiple phone numbers that present in a drop down "Emergency Dispatch", "Non-Emergency", etc.
  - You can bill player's through this, if you so desire.
  - Free-texting a service can be toggled on-and-off.

## Calling

- Calling is purely visual & for roleplay effect. Supports group calls.
- Ringing can be heard in the world from an unsilenced Agent.
- Can be minimized and place off in the corner of your screen.

## Contacts

- Since there's no actual "agent numbers", PCs can request a given contact. The PC can approve it purely as an unlinked NPC, or link it to an existing Actor.
- Contact Cards can be modified by PCs with a custom name and a notes field.
  - Yes, the GM sees all of these. Yes, it's very funny.
- GM can disable calling on certain contacts, if they wish.

## Jobs

- Simple quest log. You can also text jobs to be "accepted" by a PC and it will automatically unhide and show up in the Crew's list.

## The GM Phone

- The GM maintains their own central director phone.
- GM can "act as" an NPC for purpose of engaging with players.
- The GM generally can peek at most of what's going on with a PC's phone, including their messages, contact notes, etc.

## Apps

Number of application implementation from the All About Agent's DLC:

- Agent -> A method of providing some level of the SAAI discussed. The Agent app primarily serves as a notification center for some apps, but allow allows the GM to send notifications and advice with GM-defined answer buttons.
- The Garden -> It's social media. It does dating, sort of. See below.
- Ask Alex Anything -> DataPool access. This can be linked to the Journal to provide some automated keyword-based responses. This will prompt the GM for a reply, optionally obtaining a Library Search roll if necessary. 
- BangMe! -> Local Agent-to-Agent payments, as well as some "Pay Points". Useful for bartenders and automated admissions systems. Links into the Sheet's ledger.
- Trauma Team -> Customizable plans (in the event you have those), and a big red panic button. Can have arrival be either time-based or combat rounds (if combat is active). Can also automatically text player's asking for coverage when they are weak (gimmick, but funny). Oh and the phone get's bloody when you get below half-health (togglable by GM). You can manually provide gift coverage if necessary.
- WatchBox -> Let's the phone act as a monitor for the room, see All About Agents for this. Requires manual activation (sorry!). Defaults to ringtone but can be changed in Module Settings. The 5 minute real-world arming timer can be skipped by the GM.

## The Garden

- Largest app, with separate News and "Feed" pages, a Dating system (toggleable), and some nice GM controls. (News & Feed can be combined if desired)
- Posting:
  - Players can post similar to Twitter (contemporarily known as X), and interact with replies and "patch"-ing a post to their own profile.
  - Player's posts can have a defined "Outcome" which determines how quickly replies and sprouts (likes) are applied.
    - Outcomes can be modified at your discretion.
  - Player's can view The Garden by default, and make an account to interact.
  - Reputation Events: You can additionally tag a post to add reputation to specified players, if you'd like. This integrates with the sheet.
    - Reputation determines the PC account's "reach" and followers. (May implement more fine-tuned modifications later)
    - Media isn't treated separate, but I have a Media in my campaign currently so this may change.
  - GM's can fill in the "Messages go to" field on accounts, allowing PCs to instantly open their Messenger to that person (similar to a direct message system; just integrates with the core messenger instead)
- Queue:
  - You can generate a number of random accounts, each with some differing attitudes that determine their preset replies. Such as "bot", "conspiracy", "hater", "lurker".
  - You can then queue these accounts to post things, or a random account to post something, at certain time intervals. Can include photo attachments.
    - You can pause the queue's time progression. 
    - This allows The Garden to change as the session goes on.
  - The module includes default bios, names, and replies for each of these account types under the `/data/garden` folder.
    - These can be inspected, or edited either by file, or by uploading your own.
    - Replies, Sprouts and Patches all change overtime after a new post is made.
- Dating:
  - There is only the "match" portion that is a departure from the existing Garden Dating rules.
  - Can be done without a Garden Patch account
  - Create and customize your dating pool, alternatively form random ones from the default tags provided.
  - When a PC "activates the algorithm", you select a profile for them to match with. The PC then determines if there is a spark. The GM can then ask the PC out on a date, or the PC can message them.
  - After a Spark is made, I recommend your "date setting" to begin using the "Where is Your Date" portion of the Digital Dating in the Dark future DLC.
    - The "Keywords" table is kind of ignored. May come later.

## Customization

- While it was considered at some point to force Agent skins dependent on the one Player's had installed. I went ahead and left it as an optional choice. There is a number of skins available inspired by R.Tal's All About Agents. 
- As mentioned in the AI disclosure, I can program, I cannot design. This is all Claude's doing.
- A few skins have their own color palette options. A few are much more heavy on transparency to provide the "Internal Agent" heads-up display type of feeling.

- Players & GM can opt to use a "docked" app appearance, or a physical "home" button. Dock can either be vertical or horizontal.
- Lockscreen is an per-client toggle.
- Some apps can provide a "split view" when the window is wide. Very very helpful when managing NPC texts on the GM phone.
- Visual blood on the screen when hurt, can be toggled.
